# Organization GitHub profile

This directory contains organization-profile source that is safe to review in this repository. It is pre-production source, not evidence that an organization setting or external integration is live.

## Activation boundary

`source-ready` means the source, ownership metadata, validation, and review evidence are ready for a governed connection. It does not authorize an external mutation, credential use, workflow dispatch, or production claim.

`connected` means an approved external organization connection has been established and independently verified under the applicable governance, identity, and security controls. A source change must not represent itself as connected without that approval and evidence.
